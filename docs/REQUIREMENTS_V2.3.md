# 墨读 / InkRead 需求清单 V2.3

> **依据**：PRD V2.2（v1.6 现状对齐版，2026-09-08）× 功能差距分析（2026-09-20）
> **状态**：待评审
> **核心决策**：设备端软键盘降级为配网向导专用，查词/搜索等高频文本输入改走手机浏览器代输入（LAN/AP Web 端点）+ 语音直达（云端 ASR）

---

## 一、决策背景

### 1.1 输入通道策略调整

**问题**：五向导航键逐字移动光标的软键盘效率过低，仅适合 Wi-Fi 密码等低频短输入，无法支撑查词、书内搜索等高频场景。

**决策**：
- **砍掉"设备端软键盘做查词/书内搜索"需求**（原 R2.1 收窄为：配网向导维持现状，不再泛化）
- **主推方案一：手机浏览器代输入**（LAN/AP Web 端点，手机原生键盘打字，POST 到设备执行）
- **主推方案二：语音直达**（查词场景零输入，云端 ASR top-5 候选跳词卡）
- **可选方案三：九键多击 + 本地词典消歧**（离线兜底，仅建议作为方案一不可用时的降级路径，本期不实施）

**验收**：
- R2.1 Web 代输入端点：手机浏览器打开设备 IP → 输入文字 → 提交 → 设备执行查词/搜索并渲染结果
- R2.4 语音查词：待机页/学习页某短按直接进录音态 → 云端 ASR → top-5 候选 → 中键确认跳词卡

### R1 真机验收冲刺（v1.8 存量清零）

| # | 需求 | 类型 | 优先级 | 落点 | 验收标准 |
|---|------|------|:---:|------|------|
| R1.1 | 按 ACCEPTANCE_MATRIX 跑完 ~25 项：阅读器、FSRS/LR03、ES8311 跟读、语音查词、深睡、目录浏览 | 验收 | **P0** | 固件 | 全项 PASS，无回归 |
| R1.2 | ES8311 VAD 复标（工具化实测，替代 -35dBFS 旧值） | 标定 | **P0** | 固件+工具 | 工具输出实测阈值，写入 `mic_recorder.c` 注释 |
| R1.3 | 马达/功放/电量计接线落地并实测调优（震动时长、ui_sfx 样本、电量行上 INFO+心跳） | 硬件 | **P0** | 硬件+固件 | 震动反馈可感知；提示音可播放；设备信息页显示电量 |

### R2 输入通道与听写补全

| # | 需求 | 类型 | 优先级 | 落点 | 验收标准 |
|---|------|------|:---:|------|------|
| R2.1 | **LAN/AP 文字代输入端点**（httpd 加表单页，手机浏览器打字，POST 到设备执行查词/搜索） | **新功能** | **P1** | 固件 | 手机浏览器打开设备 IP → 输入文字 → 提交 → 设备执行查词并渲染结果；AP 门户模式下同样可用 |
| R2.2 | **听写模式会话汇总**（会话结束展示"本次听写 N 词，对 X 错 Y，错词已入错词本"；解析 payloadJson 展示上下句辅助提示） | **核心补齐** | **P1** | 固件+词库字段 | 听写会话结束显示汇总页；错词自动入错词本；上下句辅助提示可渲染 |
| R2.3 | 书内搜索接线（`reader_search` 激活，依赖 R2.1 Web 端点接收关键词） | 补全 | **P1** | 固件 | Web 端点提交关键词 → 设备执行 `reader_search` → 墨水屏跳转命中页 ✅ |
| R2.4 | **语音查词升级为一级入口**（从菜单临时视图 → 待机页/学习页直达录音态） | **增强** | **P1** | 固件 | 待机页某短按 / 学习页某短按 → 录音态 → 云端 ASR → top-5 候选 → 中键确认跳词卡 |

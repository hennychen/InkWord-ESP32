# OPM021EB 快刷攻坚与双 RAM 刷新定稿

> **硬件**：OPM021EB 2.13" ESL 电子价签拆机屏（122×250，UC8151D 兼容定制 COG，
> 厂商深圳华尔盛 HARESAN / hemoled.com，Netatmo NTH01 恒温器维修屏家族）
> **周期**：2026-08-28 ~ 2026-08-31，共三十九轮实验
> **终局**：快刷四重锁死无解；翻词滞后一帧根因为 **DTM1(0x10) 从未写入**，
> 修复 = `0x10 + 0x13` 同帧双写（三十九轮真机验证正确）；翻词定稿 ~3s OTP 全刷

---

## 1. 结论速览

| 项 | 结论 |
|---|---|
| REG LUT 快刷 | 硅级锁死：PSR bit5=1 拒 RAM 写入本身（50ms 空转），三层独立验证 |
| OTP 快刷档 | 不存在：6 组波形全为温度补偿全刷，+25~30°C=2965ms 为全 OTP 最快 |
| 打断法（POF 截短波形） | 真机证伪于"滞后一帧"，且滞后真因是 DTM1 未写（非断点续刷） |
| 翻词滞后一帧 | 根因：驱动只写 0x13（DTM2），DRF 差分引擎下屏显恒滞后一帧 |
| 修复 | `uc_refresh_bw` 加 0x10 同帧双写，一行本质变化 + 净删 146 行实验代码 |
| 遗留可选项 | 打断 + 双写组合从未测过（唯一没关的快刷之门，见 §8） |

## 2. 快刷四重锁（前情，一~三十轮）

1. **REG LUT 硅锁**：PSR `0x1F→0xBF`（bit5=REG）时 0x13/0x10 写入被拒——
   手写八轮全屏寻址、GxEPD2 标准库对照（44ms）、二十八轮 Partial Window
   寻址组合（50ms）三层验证一致，bit5 拒的是 RAM 写入本身，与寻址无关。
   ESL 定制 COG 产品定义级锁死。
2. **OTP 全量 dump**（`0xA2` ROTP + bit-bang 三线读法，归档
   `Info/opm021eb_otp/otp.bin`）：Bank0 有效（0x000=0xA5）、命令默认区未启用
   （0x00B=0xB7≠0xA5，REG 锁是硅片级）、6 组 56B 槽波形全为温度补偿全刷。
3. **温度档扫描**（`0xE0` TSFIX + `0xE5` TSSET 直写温度）：+25~30°C=2965ms
   （全 OTP 最快）、+40~100°C=3379ms、≤0°C>10s——注入完全生效但无快档，
   价签产品哲学（低频换价 + 掉电续刷）。
4. **OTP 一次性**：不可软件重烧。

规格书归档：`Info/UC8151D_datasheet.pdf`（59 页）、`Info/IL3895_datasheet.pdf`
（同系列 OPM021B1 用 SSD1608 系 COG——同系列混用 COG 的实证）。

## 3. 打断法实验（三十一~三十三轮）

**思路**：移植 ED057TC1（IL0371）实证的打断法——0x12 波形执行中 0x02 POF
打断（不等 BUSY），翻转进度从打断点继承，ED057TC1 上 250~1000ms 档目验可用。

- **三十一轮探针**（`probe_opm_abort.cpp`）：X=250~2000ms 十轮 POF/PON 轮转
  全部流程层成功（无挂死）；X=1000ms 棋盘目验可见。当时判"打断继承成功"。
- **三十二轮工程化**：`K_ABORT_MS=1000` 并入正式固件 panel_partial。真机翻词
  实测推翻：**第一次下翻旧词灰蒙蒙，第二次下翻才显示第一个词（滞后一帧）**。
- **三十三轮**：回滚并归因"断点续刷型 COG"（ESL 价签掉电续刷特性假说）。
  **该归因后被三十八轮推翻**——滞后与打断无关，是 DTM1 未写（见 §5）。

## 4. 滞后一帧排查（三十四~三十八轮）

回滚到纯全刷路径后滞后依旧，逐假设二分排除：

| 轮 | 假设 | 实验 | 结果 |
|---|---|---|---|
| 34 | POF 时机打断会话收尾 | `probe_opm_seq` A/B/C 组（立即 POF / 延时 500ms / 不 POF） | 三组全部滞后，POF 时机排除 |
| 34 | 0x92 窗口链关闭波形会话 | D2（仅加 0x92）/D1（26 轮全链） | 终态"3 条"曾误判有效；37 轮组内逐帧复核推翻——终态判据受滞后干扰 |
| 35~36 | 26 轮实证序列逐命令对齐（0x21 对 / 寄存器组 / LUT 五表） | 正式固件复刻 | 仍滞后，全部排除 |
| 37 | 二分定位破坏者 | `probe_opm_seq2` E1~E4（D1 基线逐项加回） | **8 帧全显旧图案**——比滞后更深，0x13 疑似未进显示 RAM |
| 38 | 双 RAM 假说 | `probe_opm_dram` H1/H2/H3 | **H1 定案**（见下） |

**三十八轮判据数据**（3 帧条带图 1→2→3，肉眼可数）：

| 组 | 写入方式 | 屏显序列 | 判定 |
|---|---|---|---|
| H3 | 只写 0x13（现状对照） | 3, 3, 2 | 滞后/旧图案 |
| **H1** | **0x10 + 0x13 同帧双写** | **1, 2, 3** | **完美正确** |
| H2 | 只写 0x10 | 1, 1, 3 | 部分正确 |

## 5. 机制定案：DTM1 未写

UC8151D 为双 RAM 控制器（DTM1=0x10 旧帧 / DTM2=0x13 新帧），本 COG 的
DRF 波形引擎要求 **DTM1/DTM2 同时有效（差分驱动语义）**：

- 驱动历史上只写 0x13 → DTM1 永远停在旧帧 → **屏显恒滞后一帧**；
- boot 首屏正确 = RST 后首次 0x12 完成一次内部同步；
- WFT0290/UC8253 家族的 0x10+0x13 双写惯例就是正确用法——二十四/二十五轮
  的双 RAM 差分方向本来就对，当时只是被 REG 模式 bit5 锁死；
- 打断法的"滞后"也是同一问题：三十一轮探针棋盘"可见"是单写滞后 +
  checkerboard 图案（对滞后不敏感）+ 多轮打断累计效应三者叠加的误导；
  早期"断点续刷型 COG / 波形会话冻结"假说为错误机制解释。

## 6. 三十九轮定稿（驱动终态）

`src/panels/panel_opm021eb.cpp`：

```c
/* B/W 整屏双写 + 全刷（三十九轮定稿） */
0x04 PON → 0x10 写 DTM1（同帧，差分引擎基准）
        → 0x13 写 DTM2（新帧）→ 0x12 → 等 BUSY → 0x02 POF
```

- `panel_partial` 简化为转发 `uc_refresh_bw`（partial==full 双写全刷 ~3s）；
- **删除全部实验性代码**（净删 146 行）：0x91/0x90/0x92 窗口链、LUT 五表、
  0x21 序列对、VCOM/CDI 局刷寄存器组——三十八轮证明均非必要，git 可溯；
- `partial_enabled = true`：partial 路径与 full 路径统一为双写全刷；
- 帧口径：15B/行重排（`write_ram_frame`，122px 有效行宽，非 RAM 16B 物理行宽）。

配套（同 saga 显示质量分支）：
- `epd_driver.cpp/h`：`panel_stride()` 行宽字节向上取整——OPM021EB 122px
  为首个非 8 整除宽面板（16B/行），8 整除面板零行为差异；
- `main.cpp`：122 宽默认字号提 20px（135DPI 下 16px 物理仅 3.1mm 实测发虚）、
  `UI_AUX_LEVEL` 音标/标签跟随、TINY 档行距 24→26（20px 膨胀加粗防粘连）；
- `tools/gen_cjk_font.swift`：二十四轮膨胀重构——dilate 语义从字体分派移出，
  改为主循环闭环结束后按级统一膨胀（防闭环内膨胀与 edgeTouch 伪贴边互搏）。

## 7. 经验教训

1. **UC 家族双 RAM 屏必须先确认写入语义再谈其他**：单写 0x13 的恒滞后会
   伪装成各种机制假象（断点续刷、会话冻结、窗口链缺失），先修双写再排查。
2. **探针判据须组内逐帧序列**（条带数 1→2→3），终态判据（最后一帧显示
   什么）受滞后干扰会误导（三十四轮"最终 3 条"误判 0x92 有效）。
3. **checkerboard 图案对滞后不敏感**，打断实验图案必须逐帧可辨。
4. **探针目验结论必须经真机单帧路径复核**（三十一轮多轮累计 vs 三十二轮
   单帧翻词结论相反）。
5. **真机观察会混入 UI 行为噪音**：长释义词条 NAV_DOWN 先翻释义分页再换词
   （`s_mean_page` 游标，设计行为），曾与滞后 bug 混淆判读。
6. 归因结论要随新证据迭代：三十三轮"断点续刷"归因被三十八轮推翻后，
   相关记忆全部修正、错误记忆删除。

## 8. 遗留可选项

**打断 + 双写组合从未测过**：三十一轮探针 1s 打断时棋盘可见（当时单写滞后
掩盖了真实显示目标）；若双写后打断时波形目标为当前帧，则部分驱动的当前帧
可读——1.3s 翻词的快刷可能复活（ED057TC1 的打断法快刷同为全刷波形截短，
与"OTP 无快档"不矛盾）。探针半小时可出结果；不试则当前 ~3s 定稿即终态。

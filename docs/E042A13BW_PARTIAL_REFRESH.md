## 2. 关键查证定论（datasheet 实证）

1. **无硬件窗口局刷**：命令表无 0x90/0x91/0x92（GxEPD2 类推实验全屏黑点证伪）；
   0x44/0x45 仅为 RAM 写入窗口，对显示驱动范围零约束（小窗口激活空转 150-230ms 三轮实证）。
   "Support display partial update" 的真实含义 = 差分刷新。
2. **局刷唯一正解**：`0x26`(old) + `0x24`(new) 差分 + `0x32` 写 70B 寄存器 LUT + `0x22/0xEC` 激活
   （bit4=Load LUT 寄存器路径 + bit3=Mode2 差分；去 bit5 温度位——寄存器 LUT 无需 OTP 温度补偿）。
3. **0x22 参数批次敏感**：0xC7（Waveshare demo，2020+ 批次 OTP 预载）在本屏空转 230ms；
   0xF7 全刷 / 0xEC 局刷为本屏实证值。
4. **全刷自带 OTP 重载**：0xF7 激活会从 OTP 重新加载全刷波形，局刷写入的 0x32 污染被自动洗掉。

## 3. LUT 70 字节格式（spec 图 6-6）

```
VS 区 35B（byte 0-34）：byte = 级L×7 + 组g，字节内 4×2bit = 组内 A/B/C/D 相电压
  级语义（差分模式像素对 (old,new)）：L0=黑保持 L1=白保持 L2=黑→白 L3=白→黑 L4=VCOM
  电压 2bit：00=VSS不动 01=VSH1+白 10=VSL−黑 11=VSH2
TP/RP 区 35B（byte 35-69）：每组 5B [TP_A TP_B TP_C TP_D RP]，7 组
  TP=帧数（0=跳相），RP=组重复（0=跑 1 次）；组内相序 A→B→C→D
```

**编码铁律**：电压行必须**全字节同值**（如 0x55×7 / 0xAA×7）——预发布 spec 的字节内分相电压
（0x40/0x20 类）实测不生效（见 §5 快档证伪），同值编码位序无关才可靠。

## 4. 两段式"先白后画"局刷（定稿方案）

```
段1 归白：0x26=prev, 0x24=全0xFF, k_lut_white（L2=VSH1, 8 帧 320ms）
          → 旧内容黑像素推白，历史中间灰度残留一并清零
段2 出黑：0x26=全0xFF, 0x24=new, k_lut_dark（L3=VSL, 40 帧 970ms）
          → 新黑字从纯白态单向推出，粒子推到稳定端点锁死（撤场不回弹）
```

- **残影能量学定标**：出黑 16 帧 = 粒子视觉到位未锁死（撤场弛豫回弹）；40 帧锁死（临界值）；
  归白 8 帧够（白底回弹不可见）。直接差分 (prev,new) 的黑保持像素历史残留逐次叠加——两段式根治。
- **未变化像素**：保持通道（L0/L1）VSS 零驱动，不闪烁。
- **提速栈**（2.4s → 1.3s）：局刷跳过硬复位重配（s_ready 状态自持，0xEC 不关模拟）+
  0xFC→0xEC 去温度位 + SPI 4→8MHz（FPC 排线验证）+ writeBytes DMA（RAM 传输 240→80ms）。

## 5. 证伪实验记录（防重蹈）

| 实验 | 结果 | 结论 |
|---|---|---|
| 0x22/0xFF、0xFC + RAM 小窗口 | 150-230ms 空转 ×3 轮 | 0x44/0x45 不约束驱动范围 |
| 0x90/0x91/0x92 硬件窗口 | 全屏黑点乱码 | 命令不存在，被 COG 忽略 |
| 单段直差分 16 帧（480ms） | 残影叠加 | 保持像素残留累积 + 翻转能量不足 |
| 极性交替推挤（v2） | 残影仍明显 | 方向错误：根因是保持通道不清残留 |
| 单激活多相 A10+B24/B40（850/1180ms） | 文字叠加 ×4 轮 | 预发布 spec 多相描述与芯片实测不符 |
| VCOM 交流摆动提效 | （推演排除） | 会扰动保持像素，破坏"未变区域不动" |

单激活多相波形结构时长精确生效（BUSY 与帧数严格对应）但分相电压未生效——
旧字零驱动与出新并存 = 文字叠加。深挖需逻辑分析仪，投入产出比低放弃。

## 6. SPI 铁律边界化修正

三色版 bring-up 实证"writeBytes 不落地必须逐字节 transfer"——本屏 A/B 证伪其泛化性：
该铁律仅适用于旧场景组合（1MHz + 杜邦线 + 旧 core）。8MHz + FPC 成品排线 + 当前
arduino-esp32 core 下 writeBytes DMA 显示完全正常。回退通道：`RAM_WRITE_DMA=0`。

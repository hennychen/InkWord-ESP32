## 二、逐模块详细接线

### 2.1 EPD 墨水屏（EVK011 转接板 + DEPG0370）—— 9 根线，已实测 ✅

> 驱动：GxEPD2（`GxEPD2_374_DEPG0370`，UC8253 类 COG，硬件 SPI 4MHz）。
> EVK011 板上分立升压电路由**屏幕 COG 从 FPC pin2(GDR) 自主驱动**，
> MCU 不输出 GDR/RESE 信号，仅需向 J2-16 供 3.3V。
>
> **BS 线演变（2026-08）**：省线阶段曾去 BS 线（板侧 J2-10 短接 GND，
> `EPD_BS_PIN=-1`）；重接扩展板后恢复 **GPIO11 → J2-10**，
> 固件 `EPD_BS_PIN=11` 上电驱动 LOW 选 4 线 SPI（当前状态）。
>
> **⚠️ BS 线铁律**：J2-10 只允许两种状态 —— 接 GPIO11（固件驱动）或板侧短接 GND；
> **绝不可悬空**：BS 漂高会进 3 线 SPI 模式，DC 失效、帧数据错乱、屏显条状（实测）。
>
> **v1.4 通用板补充（2026-08-22 Phase 0，未上机）**：v1.4 板上 BS 已硬接固定
> 4 线 SPI（该线不存在），固件侧 `INKWORD_BOARD_V14` 宏下 `EPD_BS_PIN=-1`，
> `epd_driver_init` 条件编译跳过驱动（与上述省线方案同路径，曾实测稳定）；
> 其余差异（24/26/34P 三合一座子、双 CS 预留、0.47R/3R 可选采样电阻、
> 板载自主升压）均为硬件属性，详见 [PANEL_COMPAT_DESIGN.md](PANEL_COMPAT_DESIGN.md) §七。
> 座子对 DEPG0370 24P FPC 兼容性待上机确认。
>
> **扩展板中继**：当前经 GPIO 扩展板转接，必须按**主板原生 GPIO 丝印**核对
>（扩展板脚位编号≠GPIO 编号的情况常见）；接触不良时 SPI 采样错位同样导致条状。

```
  ESP32-S3           EVK011 转接板              DEPG0370 屏幕
  ┌────────┐         ┌───────────────┐         ┌────────────┐
  │        │         │           J1  ├─FPC 24p─┤ COG UC8253 │
  │ GPIO7  ├─SCK────►│ J2-3 SCK      │         │ 240x416    │
  │ GPIO8  ├─SDO────►│ J2-5 SDO      │         │ GDR→板上Q1 │
  │ GPIO9  ├─D/C────►│ J2-7 D/C#     │         │ 自主升压    │
  │ GPIO10 ├─CS─────►│ J2-6 CS       │         │ VGH +15V   │
  │ GPIO11 ├─BS─────►│ J2-10 BS      │         │ VGL -15V   │
  │ GPIO13 ├─RST────►│ J2-8 RES      │         │ VCOM       │
  │ GPIO12 │◄─BUSY───│ J2-9 BUSY     │         │            │
  │ 3V3    ├─VCI────►│ J2-16 EPAPER_VCI（唯一供电脚！）│   │
  │ GND    ├────────►│ J2-1 GND      │         │            │
  └────────┘         └───────────────┘         └────────────┘
```

| ESP32-S3 引脚 | EVK011 J2 | 说明 |
|:---:|:---:|:---|
| GPIO7 | J2-3 SCK | SPI 时钟（硬件 SPI，GxEPD2 管理） |
| GPIO8 | J2-5 SDO | SPI 数据（MCU 侧 MOSI，丝印 SDO） |
| GPIO9 | J2-7 D/C# | 命令/数据 |
| GPIO10 | J2-6 CS | 片选 |
| GPIO13 | J2-8 RES | 硬复位（低有效，深睡唯一唤醒途径） |
| GPIO12 | J2-9 BUSY | 忙信号（LOW=忙） |
| 3V3 | J2-16 VCI | 屏幕唯一供电 3.3V |
| **GND** | **J2-1（必须接！）** | 共地 —— J2 无标签脚 pin1/2/12/13/14/15 均为 GND/NC，任选其一 |
| GPIO11 | J2-10 BS | 接口模式选择：固件驱动 LOW=4 线 SPI（`EPD_BS_PIN=11`） |

#### 丝印别名对照（板卡 / 屏 FPC / demo 三套命名）

| 信号本质 | J2 丝印 | 屏 FPC(J1) 规格 | demo 代码 | ESP32-S3 |
|:---|:---:|:---:|:---:|:---:|
| SPI 时钟 | SCK (J2-3) | SCL (J1-13) | SPI_CLK | GPIO7 |
| 数据线（单根双向） | SDO (J2-5) | SDA (J1-14) | SDI（读时切输入） | GPIO8 (MOSI) |
| 片选 | CS (J2-6) | CS# (J1-12) | Epaper_CS | GPIO10 |
| 命令/数据 | D/C# (J2-7) | D/C# (J1-11) | Epaper_DC | GPIO9 |
| 硬复位 | RES (J2-8) | RES# (J1-10) | Epaper_RESET | GPIO13 |
| 忙信号 | BUSY (J2-9) | BUSY (J1-9) | Epaper_BUSY | GPIO12 |
| 接口模式选择 | BS (J2-10) | BS1 (J1-8) | Epaper_BS | GPIO11（LOW=4线 SPI） |

> SDA / SDI / SDO 是同一根双向数据线的三种命名（屏厂 I2C 风格 / demo 读视角 /
> 板厂输出视角），本固件只写不读，恒接 GPIO8（MOSI）；若板卡另有独立 SDO
> 读回脚则悬空（状态查询走 BUSY 引脚）。

> **共地警告（实测教训）**: 未接 GND 时 EVK011/屏幕 COG 完全无电，
> 症状为 BUSY 悬空恒读 0、VGH 仅剩感应电压（实测 2.6V，正常 +15V）、屏幕无任何反应。
> VCI 3.3V 与 GND 缺一不可！

> **升压说明**: VGH(+15V)/VGL(-15V)/VCOM 由 EVK011 板上 boost 生成，
> 其 GDR/RESE 经 J1 FPC pin2/pin3 由屏幕 COG 自主驱动。
> **严禁将 J1 侧任何高压引脚（pin21/23/24）接入 ESP32**。
> J2 排针上无高压引脚，安全。

#### 接线精简分析记录（2026-08，结论：CS/RST/BUSY 保留，BS 两案可切换）

| 线 | 结论 | 分析 |
|:---|:---:|:---|
| SCK / SDO / D/C# | ❌ 不可去 | SPI 通信本质线 |
| 3V3(VCI) / GND | ❌ 不可去 | 供电与共地（漏接 GND 教训见上） |
| **BS (GPIO11→J2-10)** | 🔁 **当前已接**（可去） | 固件只用 4 线 SPI，BS 恒为 L。两种等价方案：①接 GPIO11 固件驱动（当前，重接扩展板后恢复）；②去线板侧短接 GND（曾实测稳定，更省一脚，但注意 GPIO11 不可再作他用且拆短接线时序风险见下） ⚠️ 切换方案时必须同步改 `EPD_BS_PIN` 并重烧，两状态不一致 = BS 悬空 = 屏显条状（实测） |
| CS (GPIO10→J2-6) | ⚠️ 不建议去 | EPD 独占总线理论可常拉低；但 ESP32 启动期 SCK/MOSI 高阻，噪声时钟可能向 COG 移入乱码命令，CS 高电平是上电窗口防误触发隔离 |
| RST (GPIO13→J2-8) | ❌ 保留 | 深睡(0x07/0xA5)唯一唤醒途径 + COG 挂死唯一恢复手段（电池设备功耗优化必需） |
| BUSY (GPIO12→J2-9) | ⚠️ 不建议去 | GxEPD2 无 BUSY 时降级固定延时（全刷1500ms/局刷350ms），变慢且低温下 COG 实际忙时长超固定值会截断波形撕裂画面；也是三态诊断排障载体 |

### 2.2 I2S 音频功放（MAX98357A）—— 已接线验证（2026-08-23，飞线直连闭环；克隆板 SD_MODE 无上拉须外接 3V3）

> ⚠️ **2026-08-20 勘误（照旧图接线会无声/音量错）**：旧版增益表写反、SD_MODE 极性写反。
> 本表已按 Adafruit MAX98357A 手册修正：**GAIN 悬空=9dB（默认）**；
> **SD_MODE 接 GND = 关断静音，勿接！** 悬空（板载上拉）或接 3V3 = 正常工作。
> ⚠️ **2026-08-23 克隆板勘误**：已购模块（92050 型，MAX98357AETE）为国产克隆板，
> **SD_MODE 无上拉电阻**——悬空 = 关断（无声）。必须外接 3V3 跳线才能正常工作。
> Adafruit 原版板有 100kΩ 上拉，悬空 = 左声道；克隆板无上拉，悬空 = 关断。
> 另：GPIO4/5 将来与 INMP441 全双工共享（BCLK/WS，见 §2.7），接线时预留。

```
  ESP32-S3              MAX98357A               喇叭
  ┌────────┐           ┌──────────┐      ┌───────────┐
  │        │     红线   │          │      │           │
  │ GPIO4  ├──────────►│ BCLK     │      │ 4Ω 3W     │
  │        │           │          │      │ 3525 喇叭  │
  │ GPIO5  ├──────────►│ LRC/WS   │      │           │
  │        │           │          │  +──►│  +        │
  │ GPIO6  ├──────────►│ DIN      │  │   │           │
  │        │           │          │  └──►│  -        │
```

| ESP32-S3 引脚 | MAX98357A 引脚 | 线色 | 说明 |
|:---:|:---:|:---:|:---|
| GPIO4 | BCLK | 白线 | 位时钟 (Bit Clock)；将来兼 INMP441 SCK（§2.7） |
| GPIO5 | LRC / WS | 黄线 | 字选择/左右声道；将来兼 INMP441 WS（§2.7） |
| GPIO6 | DIN | 蓝线 | 串行数据输出 |
| **3V3** | VIN | 红线 | 供电 3.3V（**勿接 5V**，勘误见下） |
| GND | GND | 黑线 | 共地 |
| — | GAIN | — | **悬空 = 9dB（默认）**；接 GND=12dB；接 3V3=15dB（最大，易破音）；经 100kΩ 下拉=6dB；经 10kΩ 下拉=3dB（见 Maxim 数据手册 Table 8） |
| — | SD_MODE | — | **克隆板必须接 3V3（左声道）**；Adafruit 原版悬空即可（板载 100kΩ 上拉）；接 GND = 关断静音（勿接！）；经 >633kΩ 电阻=混音 (L+R)/2；经 <210kΩ 电阻=右声道（@3.3V，见 Maxim 数据手册 §SD_MODE and Shutdown Operation） |

> **实测记录（2026-08-23）**：飞线直连（绕过扩展板）验证通过——9 声嘟音（44.1k/16k/8kHz × 3 组）
> 清晰可辨，I2S 数据链路闭环。经扩展板中继时信号劣化（BCLK 1.41MHz 边沿），
> 飞线后恢复。底噪为 Class-D 功放固有特性（~300kHz PWM 输出），克隆板缺少输出滤波
> RC 网络，贴近喇叭有嘶声属正常；正常听距（>30cm）可接受。改善方案：喇叭两端并联
> 100nF + 10μF 电容（¥1 成本）。
>
> ⚠️ **VIN=5V 勘误（2026-08-23）**：曾误接 VIN→5V，导致 CENTER 键测试音无声。
> Maxim 数据手册规定 VIH = 0.7×VDD：VIN=5V 时 VIH=3.5V，ESP32 输出高电平仅 3.3V
> **永远不够高** → BCLK/LRC/DIN 三根信号线被芯片判为全低 → 采样乱码 → 无声。
> VIN=3.3V 时 VIH=2.31V，ESP32 逻辑达标。MAX98357A 支持 2.5~5.5V，3.3V 供电
> 完全合规且与 ESP32 同电平最稳。
>
> **采样率**: 44100Hz / 16bit，标准 Philips I2S 模式。
> **增益选择**：4Ω 喇叭 + 3.3V 供电下 9dB 起步（GAIN 悬空）；若音量不足再改
> GAIN→GND(12dB)，注意大音量下 AMS1117 电流余量（§2.5 电流预算）。

### 2.3 五向导航开关 —— 已接入（2026-08；SET/RST 侧键同月扩展）

> 无源开关模块（92092/92093 类）：五个方向各一个独立触点 + SET/RST 两个
> 额外侧键（同为无源触点，模块 PDF 明示无固定功能由程序自定义），
> 公共端 COM，按下对应触点与 COM 导通。MCU 内部上拉，按下接地（低电平有效）。
> 模块丝印变体 CENTER/MID/OK 同义。
> 选脚原则：五向避开 strapping（GPIO0/3）全落 RTC 域（GPIO0~21），
> 均支持 ext1 深睡唤醒；实际接线（2026-08-18 确认）：SET→GPIO42、
> RST→GPIO40，振动马达预留从 40 改至 41，保住 38/39（I2C 预留）。

```
  ESP32-S3（内部上拉）        五向导航开关模块
                           ┌──────────────┐
  GPIO1  ◄────────────────┤ UP           │
  GPIO2  ◄────────────────┤ DOWN         │
  GPIO14 ◄────────────────┤ LEFT         │
  GPIO15 ◄────────────────┤ RIGHT        │
  GPIO21 ◄────────────────┤ CENTER/MID   │
  GPIO42 ◄────────────────┤ SET（侧键）  │
  GPIO40 ◄────────────────┤ RST（侧键）  │
  GND    ────────────────►┤ COM          │
                           └──────────────┘
```

### 2.4 MicroSD 卡模块（已购款：板载稳压/电平转换，SPI3_HOST）—— 已接线实测（2026-08-23，SPI 链路通；exFAT 128G 挂载失败待换卡）

> **已购模块**：淘宝「Micro SD 卡模块 SPI 接口」（卖家手册 MicroSD Card Adapter
> v0.9b，2013-07-15）。规格：自弹式卡座；**板载 3.3V LDO + 电平转换电路**，供电
> **VCC 4.5~5.5V（典型 5V）**，接口电平 3.3V/5V 自适应；支持 MicroSD（≤2G）与
> MicroSDHC 高速卡（**≤32G**，不支持 SDXC/exFAT）；42×24×12mm、5g、4×M2 定位孔。
>
> ⚠️ 引脚与旧版文档不同：SD 已改用 **GPIO16/17/18/47**（旧 GPIO10-13 已被 EPD 占用）。
> ⚠️ **VCC 勘误（2026-08-23，依模块手册）**：本模块 VCC 须接 **5V**（DevKitC-1 的
> 5V 脚，USB 供电路径）——板载 LDO 需 ≥1V 压差，**3.3V 直供时卡芯仅得 ~2.2V**，
> 低于 SD 规范 2.7V 下限，部分卡侥幸可读但不可靠，禁止按旧图接 3V3。
> 电平方向：MCU→卡（SCK/MOSI/CS，ESP32 3.3V 输出）经板载转换适配；卡→MCU（MISO）
> 恒为 3.3V，ESP32 直读安全、无 5V 倒灌风险。
> 实测未接线时挂载失败（`sdmmc_init_sd_if_cond 0x108`）不影响其他模块运行。

> TF 卡，固件 inkword-s3 烧录启动：**无 sdmmc probe 报错**（对比未接线时的

> 固件正常降级（内嵌词库 2407 词，`no /sdcard/books` 仅警告）。
> **下一步**：换 FAT32 ≤32G 卡复测，预期 `SD card mounted at /sdcard` +

> （代价：放弃 I2C 电量计/RTC 预留）。**当前不接线，接线前须回读本节确认方案。**

| GPIO | 来源 | 说明 |
|:---:|:---|:---|
| **38** | 一直未占用 | 无限制，I2C 电量计/RTC 预留（SDA/SCL）；INMP441 DOUT 备选（§2.7） |
| **39** | 历史预留 GDR 已废弃（升压由屏 COG 自驱，见 §2.1） | 兼具外部 JTAG TCK 复用；INMP441 DOUT 备选 |

> GPIO41 已划给震动马达（固件 haptic.c 落地，§2.6）；21/40/42 已被
> NAV_CENTER / NAV_RST / NAV_SET 占用（2026-08-18 接线确认），均移出空闲池。
> INMP441 DOUT 首选 BS 省线释放的 GPIO11（§2.7），38/39 仅作退路；
> 若放弃 I2C 电量计则 38/39 可整体让位（GAP_ANALYSIS §6.3）。

### 4.2 状态灯建议：GPIO48 板载 WS2812 RGB（零接线）

DevKitC-1 **板载 WS2812 RGB LED 接 GPIO48**，无需任何接线即可用作状态灯
（Arduino 核心已内置 `RGB_BUILTIN` 宏，`neopixelWrite()` 直接驱动）。
建议优先启用 GPIO48 做状态灯，**彻底解除 GPIO14 的 LED/KEY_E 历史冲突**
（见 §2.3），且不占用 4.1 空闲池。

### 4.3 永久闲置：GPIO45 / GPIO46（strapping）

| GPIO | strapping 功能 | 闲置原因 |
|:---:|:---|:---|
| **45** | VDD_SPI 电压选择 | 上电采样须为低（高=1.8V flash 供电模式），外接上拉可致无法启动 |
| **46** | 启动模式 / ROM 日志控制 | 上电采样须为低，外接上拉/按键可致启动异常 |

> 这两脚的上电采样值直接决定启动配置，**禁止外接上拉、按键或强驱动器件**，
> 建议在接线与 PCB 层面永久闲置。

### 4.4 ADC 限制与电池电压检测方案

ESP32-S3 ADC 通道分布 × 本项目占用情况：

- **ADC1 = GPIO1–10**：已被按键 / I2S / EPD 占满，无可用通道；
- **ADC2 = GPIO11–20**：GPIO11 被 EPD_BS 占、12/13 EPD、14/15 按键、
  16–18 SD、19/20 USB —— **同样无空闲通道**（且 Wi-Fi 开启期间 ADC2 采样被禁用）。

结论：本项目已无现成可用的 ADC 引脚，电池电压检测推荐走 I2C：

| 方案 | 引脚 | 原理 | 优缺点 |
|:---|:---|:---|:---|
| ① I2C 电量计（推荐） | GPIO38/39 作 SDA/SCL | 外置电量计 IC（如 MAX17048）直接读电压/百分比 | 无 Wi-Fi 限制、精度高；增加 1 颗 IC 成本 |
| ② 复用 BS 脚分时采样 | GPIO11 + 分压电阻 | 深睡前屏已静止时将 BS 脚短暂切 ADC 采样一次，读毕恢复输出 LOW | 零成本；属复用 hack（BS 脚兼 4 线模式选择与 ADC），需验证 COG 静止期 BS 悬空无副作用 |

```
  ┌─────────────────────────────────┐
```

### 5.2 去耦电容

| 器件 | 电容规格 | 位置 |
|:---|:---|:---|
| ESP32-S3 VCC | 10μF + 0.1μF | 尽量靠近 3V3/EN 引脚 |
| EVK011 VCI (J2-16) | 10μF + 0.1μF | 靠近 J2-16（升压电流瞬时抽吸） |
| MAX98357A VIN | 10μF + 0.1μF | 靠近 VIN 引脚 |
| SD 卡 VCC | 10μF + 0.1μF | 靠近 VCC 引脚 |

> 注：VGH/VGL/VCOM 高压电容组在 EVK011 板上已集成（Q1+L1+MBR0503 boost），PCB 侧无需重复。

### 5.3 走线建议

| 信号 | 线宽 | 注意 |
|:---|:---|:---|
| 电源 (3V3/GND) | 20mil+ | 尽量短粗 |
| I2S 音频 | 8mil | 等长走线，远离开关电源 |

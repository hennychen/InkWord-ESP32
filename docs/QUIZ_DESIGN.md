## 1. 背景与目标

现复习模式（2026-08-24 词表化改造后）为「到期词列表 + 词卡详情 + 左/右自评」，
自评质量完全依赖用户主观判断。百词斩的核心经验：**客观题（四选一）把「回忆强度」
转化为「可测量的作答行为」**，答对/答错直接映射 SRS 质量，降低自评负担并提升
复习趣味性。

目标：
- T1/T2 两题型四选一（P1），听音辨义 T3（P2 探索）；
- 作答结果直接走 `learning_state_apply_quality`（FSRS-4.5），与左/右自评同源；
- 零新增持久化：题面与干扰项全部运行期派生。

非目标：拼写作答（听写模式已覆盖）、例句填空（无例句数据）、图片题（无图库）。

## 2. 题型定义

| 题型 | 题干 | 选项 | 感官通道 | 优先级 |
|------|------|------|----------|--------|
| T1 看词选义 | 单词 + 音标 | 4 个中文释义首行 | 视觉 | P1 |
| T2 看义选词 | 中文释义（可 2 行） | 4 个单词 | 视觉 | P1 |
| T3 听音选义 | 自动播词音 | 4 个中文释义首行 | 听觉 | P2（已实施 v1.5） |
| TF 判断 | 单词 + 待判释义 | 对 / 错（2 选） | 视觉 | v1.5 T5.2（已实施） |

**配对题 = 四选一变体（零代码确认，T5.2）**：T1/T2 本质即配对
（题面↔答案互选，化学式↔名称 / 问题↔答案 / 词↔释义同构——qa
卡组 front/back 映射 slot 0/1 即配对语义），不另设题型枚举。

判断题陈述构造：answer=1（真）释义来自题词；answer=0（假）释义
来自文本互异的干扰词；假陈述干扰无解（同义库）时兜底全真——
正确性齐套优先，不论难度分布。作答槽位语义复用四选一判定
（sel==answer），quiz_session_answer 零改动。

选项文案复用词卡渲染规则：释义取首行截断（同复习词表右列 16px 单行策略），
T1/T2 选项均为「一屏四行」短文本，避免长释义排版分页。

## 3. 出题算法（运行期，零持久化）

```
题池：优先 FSRS 到期词（learning_state_due_at 视图复用），
      不足 N 题时以「stability==0 新词」补足，再不足随机全库；
每轮：QUIZ_ROUND_N（默认 10）题，题池内不放回抽样；
题型：T1/T2 交替（奇偶），防同型疲劳（v1.5 已实施）；T3 占据偶数槽，
      逐题探测音频可用性，无音频降级 T1（开放问题 1 定案）；
      判断题（T5.2）占 i%4==3 槽位（每 4 题一道，10 题轮约 2 道），
      QUIZ_F_TRUE_FALSE flag 注入可关；
干扰项：题池外随机采样 3 词，满足：
  ① 释义首行与正确项及彼此互不相同（截断后比较）；
  ② 与题词不同词性倾向的释义可致歧义——P1 不做词性过滤，仅做 ①；
  ③ P2 变体（提难度）：同首字母 / 相近长度优先采样（v1.5 已实施：
     同首字母经 quiz_text_fn slot 2 前缀，干扰项三阶段采样——同前缀
     优先→文本去重→索引兜底，小组耗尽自然回退；前缀取 text 首个
     UTF-8 码点，英文首字母 / CJK 首字全科目泛化）。
```

随机源：`esp_fill_random`（硬件 RNG），会话内一次播种即可。

## 4. 作答 → FSRS 质量映射

| 作答 | quality | 说明 |
|------|---------|------|
| 选错 | 1（Again） | `consecutive_wrong++` 自然入错词本 |
| 选对 | 4（Good） | 客观题无法区分 Easy/Hard，固定 Good |
| 跳过/超时 | 不评分 | 直接换题（词保留到期状态，下轮再推） |

与现有左/右自评（Q1/Q5）的关系：测验是**另一种复习入口**而非替代；
两条路径都汇入 `learning_state_apply_quality`，今日统计（today_reviews）
同口径累加，lr_stats 无需感知来源。

## 5. 版式与按键（P1 纵列范式）

复用全机一致的列表交互（menu_ui / 复习词表同范式），降低学习成本：

```
┌────────────────────────────────┐
│ 测验  3/10        （状态栏）     │
├────────────────────────────────┤
│  abandon                        │  ← 题干：单词 FreeSans 大字
│  /əˈbændən/                     │  ← 音标 16px 点阵（T2 时为释义）
│                                │
│ ▓ easily  放弃      (A)         │  ← 反选高亮行（黑底白字）
│   give up  放弃      (B)        │
│   leave  离开        (C)        │
│   follow  跟随       (D)        │
│                                │
│ 上/下 选择 · 中 作答            │  ← 提示栏（TINY 省略）
└────────────────────────────────┘
```

- 题干区高约 1/3 内容区；选项区 4 行独立行高（可用区四等分与
  `RV_ITEM_H` 取小，2026-08-25 真机反馈收窄：MID 416x240 沿用
  RV_ITEM_H=44 时 D 项出屏且测验选项恒 4 项无滚动语义，收窄后
  行高 27；4.2 寸 400x300=37；TINY 竖屏充裕维持 28；SMALL
  264x176 纵列四行数学上放不下，恒走 P2 网格）；
- 按键：**上/下 = 移动选项（A↔D 循环），中 = 作答并即时反馈，
  SET = 跳过，RST = 中途退出（已答题保留评分）**；
- 作答反馈：答对→选项行保留高亮 + 震动 30ms 即切下一题（局刷）；
  答错→正确项反白闪烁一次 + 错误项打 ×（局刷两拍，约 0.7s）后切下一题；
- 答完小结页：「对 8 · 错 2 · 复习 10」+ 任意键退出（全刷，低频）。

### P2 变体：2×2 方向直选（快答模式，v1.5 已实施）

四选项 2×2 网格，上=左上/右=右上/下=左下/左=右下一步作答（省「中」键确认）。
墨水屏局刷一次一拍，方向直选每题仅一次刷新（纵列需移动+确认两拍）；
代价是象限-方向映射需适应（左下=下 or 左 存在歧义），真机试用后再定夺。

实施（T5.1）：设置页「测验快答」开关（set_quizgrid，默认关=纵列基线
保留可对比）；**T3 恒直选**不受开关控制——听音题四向四选项天然配套，
中键留给重播（纵列 T3 无重播键位，SET 已被跳过占用）；直选模式下
中键 = 重播当前题词音（T1/T2 亦可用作听音复核，缺源短震）；题干区
与反馈态（对=高亮保留 / 错=两拍反白+×）语义同纵列迁移。

### 判断题版式（v1.5 T5.2）

恒纵列两选项（「错 / 对」固定文案，槽 0/1），不参与 2×2 直选
（两选项不适合四向网格）；**左右键直答两模式均启用**（左=错 /
右=对），上/下两槽循环 + 中作答兼容；中键重播（听音复核）；
题干 = 单词大字（题干区上部 2/3）+ 待判释义行（紧贴选项区顶）；
音标略去（视觉降噪，判断焦点在词义配对本身）。

## 7. 数据流

```
menu_ui「快速测验」→ study_mode_enter_quiz()（前置：词库 ≥ 8 词）
  → quiz_session_start(题池 N=10)   ← learning_state_due_at / word_parser
  → ui_draw_quiz()（首帧全刷）
按键 → quiz_session_answer(sel) → 对比正确项
      → learning_state_apply_quality(idx, 1|4)   ← 今日统计/FSRS 同源
      → 反馈渲染（局刷）→ 下一题 / 小结页
```

native-test 可测性：quiz_session 的出题（干扰项去重/放回抽样）与评分映射
为纯函数，与 learning_state 解耦后可进 `test/`（同 srs_engine 先例）。

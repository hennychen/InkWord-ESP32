# ED057TC1 黑白局部刷新探索全记录（v4.37k ~ w6）

> 面板：元太 ED057TC1 5.65" 600x448 Spectra 黑白黄三色，24P FPC
> 控制器：UC8179/UC8253 过渡型定制 COG（v4.38 指纹探针定型：仅 0x71 FLG
> 可读 0x13↔0x15 动态、0x2F/0x3C/0x3D 浮空不可读；RAM 0x10/0x13 生效、
> 0x24/0x26 无效；0x01 双字节 + CDI 0x50 双字节 + 六 LUT 0x20~0x25 生效）
> 工作文件：`Info/ink_test/ink_test.ino`（v4.37 系）
> 结论日期：2026-08-29

## 一、目标与约束

- 目标：数字/文本区域局部刷新——黑字、无黄、无残影、闪烁范围收缩到窗口
- 4bpp 语义（OTP 三色模式实证）：0x0=黑、0x3=白、0x4=黄；2 像素/字节
- 基础时序：全刷 22710ms（OTP 三色波形）、PWR 忙窗 70ms、BUSY LOW=忙

## 三、终局物理边界（十六版穷尽后的定论）

1. **快速波形全部不驱动像素**：REG 六表（任意写法 70~500ms）、OTP 快速组
   （三件套切出的 49ms）均为空波形。Spectra 三色屏 OTP 只含全刷波形，
   厂家未做局刷支持——「窗口区局部闪」**无物理载体**。
2. **闪烁范围不可收缩**：OTP 波形全屏扫描，打断只截短时长不缩范围；
   闪烁感知由波形起始的全屏翻转脉冲主导（125ms 与 500ms 感知相同），
   档位只影响刷新周期。
3. **显示唯一路径**：OTP 默认波形（22.7s 全刷）或其打断截取（打断法）。
   窗口写（0x91/0x90/0x92，PT_SCAN=0，x 8px 对齐）数据确实进 RAM。
4. **换屏建议**：真「无闪窗口局刷」需黑白屏（如 DEPG0370/UC8253：
   无窗口整屏双 RAM 差分，COG 跳过不变像素，闪烁只出现在变化区）。

## 四、最终方案：打断法（w6 实证参数）

```
初始化（上电一次）:
  RST 脉冲 20ms × (H20-L20-H20) → 等 BUSY 闲
  0x01 37 00        POWER
  0x00 CF 08        PSR（三色 4bpp OTP 模式）
  0x06 C7 CC 28     booster 软启动
  0x30 3C           PLL
  0x41 00           温度组
  0x50 77           CDI
  0x60 22           TCON
  0x61 02 58 01 C0  TRES 600x448
  0x82 3B           VCOM_DC
  0xE5 03           FLASH MODE
  0x04              PON（忙窗 ~70ms）

完整刷（静态页/残影清洗，22.7s）:
  0x91 / 0x90 窗口(x8对齐, PT_SCAN=0) / 0x10 4bpp BW 平面
  / 0x13 4bpp 黄平面 / 0x92 / 0x12 / 等 BUSY 22.7s

局部刷新（打断法，周期 = 档位 + ~34ms 传输）:
  0x91 / 0x90 窗口(x8对齐, PT_SCAN=0) / 0x10 4bpp BW 平面 / 0x92
  0x12 → delay(125~500) → 0x02 POF → 立即下一轮
  （不等 BUSY；POF 后无需 PON，0x12 自带；黄平面不动=黄静态保持）
```

- 4bpp 合成：BW 平面 bit=1→nibble 0x3（白）/bit=0→0x0（黑）；
  黄平面黄位→0x4 / 非黄→0x3
- 打断档 125/250/500ms 均清晰无残影；闪烁感与档位无关 → 推荐 125~250ms
- 混合策略：连续打断局刷 N 次（建议 8）后插一次完整刷清洗（settle 残影）

## 五、证伪清单（勿重试）

- REG 六表差分（KW/WK=0x5A/0x84 任意组合、swap、kw_level、N2OCP=0x39/0x29）
- 1bpp 假说（v4.37i「1bpp 定案」系 OTP 回退刷误判，w3 复验证伪）
- PT_SCAN=1/0 对显示无影响（v' 单变量否定）
- PSR2=0x0d 单变量、CDI/E0/E5 三件套（切波形组但快速组为空）
- 0x21 DUC1 Normal/Bypass/Inverse
- 内容与触发分离（0x10 线性内容+0x13 窗口触发——310ms 快刷不显示任何内容）
- 全屏差分 2.7s 复现（e 版/c1 均为 COG 电荷历史孤例，s/t/u 三路径 22.77s）
- 0x24 灌数据（非本 COG RAM 命令，30s 卡死）

## 七、固件真机 Bring-up 补记（2026-08-29，inkword-s3-ed057tc1）

移植后真机三轮排障（每轮均在试屏板直烧验证）：

| 轮次 | 症状 | 根因 | 修复 |
|---|---|---|---|
| 1 | 0x12 空刷（BUSY 忙窗仅 10ms，boot 清屏 2.5s 即过） | **SPI 4MHz 数据完整性**：杜邦线环境 COG 收错窗口/数据→拒收；ink_test 全部位控慢速所以从未暴露 | 降 1MHz（SPISettings） |
| 2 | 1MHz 后 0x12 真跑 22.7s 但屏面不变（RAM 数据未进） | **窗口会话 0x91/0x90 在固件环境不进 RAM**（xe=599/592/607 三参数同症状；ink_test 位控同参数有效——差异未定位） | 完整刷改无窗口直写（0x10/0x13 直写，il0371_fill 姿势）——屏面正确显示学习页 |
| 3 | partial 打断法翻页残影重叠 | **125ms 打断对全屏密集黑字翻白不充分**（ink_test 实证前提=小窗 240x128 稀疏数字+白底基态；真实场景整页密集黑字） | 500ms 档+直写仍不彻底 |

**终局裁决（用户 2026-08-29）**：该屏无法实现高效局部刷新——翻页过慢
（~2.7s/页）且字体显示不清晰；**定位改静态页面显示**（数据传图走
write_full 直通），退出单词机交互屏候选。落地：desc `partial_enabled=false`
（L3 自动降级全刷）、partial_ms=23000、partial_count_full_refresh=0。

附带修复（保留在面板单元）：
- `wait_refresh_done` 两段式（①等 BUSY 进入忙 ≤300ms ②等释放）——
  单段式在 BUSY 置位延迟期提前退出，0x12 从未被等待
- boot stamp 时间线（sd→keys 间隔）可作为「清屏是否真跑」的快速判据
- 1MHz 下整屏传输 ~2.2s/面（600x448x4bpp）

## 终局：放弃适配（2026-08-30 褪色实证链）

静态显示定位下遭遇**画面保持失效**：内容显示后 1~2 分钟整体变淡消失
（黑点残留）。系统性实证链（全部真机）：

| # | 方案 | 结果 |
|---|---|---|
| 1 | PON 保持（无尾部命令） | 褪色 |
| 2 | 0x02 POF（完成掉电 2.7s） | 褪色 |
| 3 | POF+3s 等完整掉电 | 褪色 |
| 4 | 复触发 0x12+500ms+POF（嫁接打断态） | 褪色 |
| 5 | POF+50ms+DSLP(0x07/0xA5) | 褪色 |
| 6 | 直入 DSLP（跳过 0x02） | 褪色 |
| 7 | DSLP+RST 拉低+CS/DC 高阻（软件拔线） | 褪色 |
| 8 | 禁 WiFi（排除射频/电源干扰） | 褪色 |
| 9 | 保持任务 60s 周期 125ms 打断补刷 | 补刷量杯水车薪 |
| 10 | 保持任务 1s 周期（对齐 ink_test 数字循环） | 未及终验，用户裁决放弃 |
| 对照 | **显示瞬间拔 USB（整机断电）** | **长期稳定** |
| 对照 | ink_test 数字循环（每秒打断刷） | 稳定=持续补刷维持 |

**结论**：供电下面板画面分钟级自然衰减（衰减率 ~1%/s），软件层无解
（衰减源在 VCI 持续供电的硬件路径）；断电虽可保持但产品不可行，
秒级补刷与静态显示定位冲突。**判定该面板（或本屏+EVK011 组合）
不适合本项目，放弃适配。**

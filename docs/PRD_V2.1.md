## 二、产品概述

### 2.1 产品定位

**墨读 / InkRead** 是一款基于 ESP32-S3 的 3.7 寸墨水屏英语学习设备，面向 K-12 学生及英语学习者，提供**护眼沉浸式单词学习 + 电子书阅读**双核心体验。

### 2.2 核心价值

| 维度 | 价值主张 |
|:---|:---|
| **护眼** | 墨水屏无蓝光、不闪烁，适合长时间学习与阅读 |
| **专注** | 无社交干扰、无推送，回归学习本身 |
| **科学** | SM-2 间隔重复算法驱动的智能复习系统 |
| **沉浸** | 五向摇杆 + SET/RST 侧键共 7 键、长短按 14 语义槽，单手盲操 |
| **完整** | 硬件 + 固件 + 云端 + App 全栈方案，数据多端同步 |

### 2.3 目标用户

| 用户画像 | 使用场景 | 核心诉求 |
|:---|:---|:---|
| 初中生（13-15岁） | 日常背单词、预习教材 | 教材同步、护眼、无手机干扰 |
| 高中生（16-18岁） | 高考词汇冲刺 | 科学复习、高效刷词 |
| 英语自学者 | 碎片时间学习 | 沉浸体验、学习数据可追踪 |
| 极客/DIY爱好者 | 开源二次开发 | 可定制、可扩展 |

### 4.3 硬件设计红线（V2.1 改写）

| 风险 | 对策 |
|:---|:---|
| Strapping 误用（GPIO0/3/45/46） | 禁止外接上拉/按键/强驱动；45/46 在 PCB 层面永久闲置（上电采样决定启动配置） |
| **BS 线悬空**（EVK011 实测铁律） | J2-10 只允许两态：接 GPIO11（固件驱动）或板侧短接 GND；悬空 → 3 线 SPI 模式 → DC 失效、条状花屏（实测） |
| 共地缺失 | J2-1 GND 必接；漏接症状：BUSY 恒 0、VGH 仅剩感应电压、屏幕无反应（实测教训） |
| 高压安全 | EVK011 板载 boost 由屏 COG 从 FPC pin2(GDR) 自主驱动，**MCU 严禁输出 GDR/RESE**；严禁 J1 侧高压引脚（pin21/23/24）接入 ESP32；J2 排针无高压，安全 |
| 供电 | 现阶段开发板 3V3 已验证；量产 PCB 屏 VCI 用独立 LDO 承载升压瞬时电流（电流预算 ~310mA 峰值） |
| FPC 排线应力 | 外壳设计排线固定压板，弯折半径 ≥5mm |
| 扩展板中继 | 按主板**原生 GPIO 丝印**核对（扩展板脚位编号 ≠ GPIO 编号，实测踩坑） |

### 5.6 刷新调度策略（2026-08-20 无窗口方案定稿，详见固件 README「局部刷新方案」）

```cpp
// 基线（epd_driver + refresh_scheduler，README 规则 1-8）：
//   局刷统一走 epd_gfx_flush_window*：无窗口整屏双 RAM 差分
//   （硬复位 → partial 波形初始化 → 整屏写 0x10 旧帧 + 0x13 新帧
//   → 0x04/0x12×passes/0x02；窗口参数仅做区域合法性检查）；
//   禁用 partial window（0x91/0x90，实测均不能干净刷白）；
//   局刷计数阈值：学习/阅读页 N=8（refresh_scheduler_init），
//   待机页 N=12（refresh_gfx_before_partial_n）；全刷为低频深度保养
//   （双 RAM 差分局刷自身无残影）；待机页大面积变化（引文带差分>25%）
//   直接分流全刷；遗留窗口直通 API（refresh_submit/epd_partial_refresh）
//   已删除，杜绝绕过双 RAM 差分的路径。
每次局刷前（refresh_gfx_before_partial[_n]）：
  如果 局刷计数 >= 阈值：
    计数 = 0; return true;   // 调用方整屏重绘后走真全刷（不预清屏）
  否则：
    计数++; return false;    // 调用方局刷（默认双刷 passes=2）
外部全刷（LAN 直传整帧 / 模式切换）：
  refresh_notify_full_done(); 计数 = 0;   // GFX previous 已失配，
  ui_force_full_refresh_next();           // 下次渲染强制全刷
```

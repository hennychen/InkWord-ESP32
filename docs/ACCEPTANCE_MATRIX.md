## 执行总序（拓扑序）

```
P0 硬件 bring-up（ES8311 录音链是第一块多米诺）
 └─→ A 音频功能链（四条功能线压在录音链后）
 └─→ B 学习链回归（无音频依赖，与 P0 可并行开工）
      └─→ C 同步与账户链（依赖 B 的切书/学习基线）
           └─→ D 三端全链（依赖 C 的同步基线）
D 整机指标（随时可插，建议最后收口）
```
